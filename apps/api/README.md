# GeoOps API

FastAPI gateway for GeoOps AI. It exposes health, operational catalogs, route-aware dispatch, provider-neutral maps, cited knowledge retrieval, typed agent orchestration, and human approval endpoints. The default maps, embedding, agent, and approval implementations need no credentials. Google ADK, Google Maps, Vertex AI, and Firestore adapters are selected through validated server-side configuration.

From the repository root, start it with `make api` and open the generated API documentation at <http://localhost:8000/docs>.
